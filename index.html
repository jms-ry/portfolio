Pawrtal

A full-stack web-based animal rescue management system built as an undergraduate thesis for Ormoc Stray Oasis (OSO). Handles adoption applications with automated approval workflows, donation processing via PayMongo (GCash), rescues and reports management, and role-based authentication.

BukidCheck

A weather-based farm task feasibility checker for Filipino farmers. Analyzes real-time and 3-day hourly forecasts to determine if tasks like pesticide spraying, harvesting, or sun drying are safe to perform — and suggests the best time window if conditions are unfavorable.

Live Project React Vite Open-Meteo API Nominatim Vercel

PesoSense

A money-spending tracker that helps users log expenses, manage savings, and set and fund financial goals. It provides clear spending breakdowns and dynamic insights to show where money goes and how to save more effectively. All data are stored locally in the browser, with export and import features to enable easy syncing across devices.

Live Project React Vite Vercel
🦘
⭐ GitHub

ShopHop

A mobile shopping trip planner for buying across multiple stores without forgetting an item. Items are grouped by store (or tagged "Any store"), and each store gets its own screen where items are marked bought or no stock. Unbought and no-stock items carry forward to the next store, trips can be resumed, and finished trips are saved as receipt-style journeys. All data is stored locally on the device.

Mobile App React Native Expo TypeScript SQLite EAS Build
